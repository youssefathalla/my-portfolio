## 3. Commercial Rules & Block Invariants

1. **Four Hour Blocks Available**:
   - **1-Hour Advisory Call**: Fast architecture consultation, schema review, or migration strategy.
   - **10-Hour Starter Block**: Focused bug sweeps, isolated component build, or small screen set.
   - **20-Hour Growth Block**: API integration, reactive state wiring, small feature backlog.
   - **40-Hour Scale Block**: Sustained sprint demand, multi-feature module execution.
2. **Carry-Forward Guarantee**: Unused prepaid hours in a block **never expire** during the project cycle and roll over into subsequent feature tasks.
3. **No Retainer Requirement**: Purchase single blocks on-demand as needed.

### 4.3 Transparency Model (`<h2>How Billing Stays Transparent</h2>`)

- **Pre-Approval Estimations**: Every task is scoped and estimated in hours before work begins, so you approve the time allocation before it is spent.
- **Asynchronous Demos**: Progress is demonstrated through short recorded walkthroughs or a shared preview staging link, not status reports alone.
- **Real-Time Shared Time Logs**: Time is logged per task in a shared tracker (Toggl/Clockify/Notion) accessible 24/7.
- **Unified Communication Channel**: All updates run through a single agreed channel (Slack, Teams, or Email).
- **Rollover Guarantee**: Billing reflects hours actually worked; unused hours carry forward.

### 4.5 Frequently Asked Questions (FAQ)

1. **How do I track how many hours have been used?**
   - _Answer_: Every minute spent is logged with task descriptions in a shared real-time dashboard. You receive weekly summaries and can check the balance at any time.
2. **What happens if a task takes less time than estimated?**
   - _Answer_: You are only billed for the time worked. The remaining balance carries over to your next task or backlog item.
3. **What happens if a task exceeds the estimated hours?**
   - _Answer_: If scope complexity changes during implementation, I stop and notify you before exceeding the estimate so you maintain full control over hours spent.
4. **How do we hand off designs and tasks?**
   - _Answer_: You can share Figma files, Jira/Trello tickets, or a simple bulleted document. I review requirements, ask clarifying questions, estimate the hours, and start once approved.
