## **3\. Primary Service Offerings**

### **🛠️ Core Engineering Packages**

#### **1\. Full-Stack Serverless Web Apps**

- **Scope:** Turnkey web applications built from scratch.
- **Tech:** Angular front-end, Firebase Authentication, Firestore database design, Cloud Functions, security rules, and third-party payment integrations.
- **Best For:** Startups, founders, and businesses that need a complete, production-ready product.

#### **2\. Cloud & API Integrations**

- **Scope:** Integrating external APIs and cloud services directly into modern web platforms.
- **Tech:** REST/GraphQL integrations, Firebase Cloud Functions, Stripe and third-party payment gateways, and real-time Angular Signal state synchronization.
- **Best For:** Platforms needing third-party service connections, webhook automations, or payment workflows.

#### **3\. Modern Angular Front-End Engineering**

- **Scope:** Enterprise-grade front-end development for existing backends.
- **Tech:** Angular Standalone Architecture, Angular Signals state management, RxJS streams, and REST/GraphQL API wiring.
- **Best For:** Engineering teams needing high-performance UI layers over Node, ASP.NET, or Java microservices.

#### **4\. Multi-Tenant SaaS & Enterprise Dashboards**

- **Scope:** Complex B2B platforms with multi-tenant data isolation and security.
- **Tech:** Role-Based Access Control (RBAC), dynamic data visualization, bi-directional English/Arabic (RTL/LTR) layouts, and tenant switching.
- **Best For:** SaaS founders, logistics providers, and corporate operations teams.

#### **5\. Angular Legacy-to-Modern Upgrades**

- **Scope:** Refactoring legacy Angular codebases (v10–v15) to modern standards.
- **Tech:** NgModule removal, Standalone Component migration, RxJS-to-Signals state conversion, and OnPush performance tuning.
- **Best For:** Enterprises with sluggish, hard-to-maintain legacy Angular applications.

#### **6\. Figma / UI Design to Angular Code**

- **Scope:** Converting visual designs into responsive, accessible, production-ready code.
- **Tech:** Tailwind CSS, Angular Material (MD3), WCAG 2.1 AA accessibility compliance, and CSS logical properties for native LTR/RTL support.
- **Best For:** Agencies and design-led teams lacking front-end engineering bandwidth.

## **6\. Fair-Play Scope & Revision Policy**

To eliminate scope creep while ensuring total clarity for clients:

> **1\. Requirement & Design Phase:**  
> All project specifications, user flows, and wireframes can be modified freely before development on that specific feature begins.  
> **2\. Unbuilt Features (During Development):**  
> If a feature has not been coded yet, the client can swap its requirements for a different feature of equal engineering complexity at zero additional cost.  
> **3\. Coded & Approved Features:**  
> Once a feature has been built, tested, and accepted, modifications to its core logic or UI will be quoted transparently as a Change Order sprint (fixed-rate or hourly).  
> **4\. New Feature Requests:**  
> Any new ideas outside the original scope are estimated separately as add-on sprints before any work begins.

## **8\. Operational Rules & Working Policies**

- **Project Pause & Delays Policy:** Unresponsive delays exceeding 14 consecutive days on the client's end (e.g., missing assets, API credentials, or feedback) will automatically pause the project schedule. Resuming requires a 3-business-day re-boarding notice.
- **IP Transfer & Ownership Gate:** Full source code ownership, production repository transfers, and live server deployments are handed over upon receipt of the final payment installment.
- **Communication Standards:** Primary communication takes place asynchronously via Slack/Teams with bi-weekly Loom video walkthroughs. Fixed-scope projects include one 30-minute sync call per week.
- **Working Hours & Emergency SLAs:** Standard business hours are Sunday through Thursday, 9:00 AM – 6:00 PM (EEST). Emergency out-of-hours hotfixes are billed at 1.5x the standard hourly rate.
- **AI IP Isolation Guarantee:** All AI-assisted workflows (Kiro, Cursor, Antigravity) enforce local context rules (.kiro / .cursorrules) to ensure zero exposure of proprietary client code to public model training data.
