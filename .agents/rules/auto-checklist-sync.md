# Auto-Checklist & Learning Reference Rule

Whenever a new concept, technique, prompt engineering pattern, or API milestone is discussed, tested, or implemented in this project:

1. **Mandatory Documentation in `CHECKLIST.md`**:
   - Automatically append the new topic to `CHECKLIST.md`.
   - Provide a clear, simple "Why / Analogy" explanation so the user can easily review it later.
   - Include a minimal, runnable code or prompt snippet.

2. **Roadmap & Progress Sync**:
   - Keep checkboxes `[x]` up-to-date.
   - Keep file paths and npm command references accurate.
